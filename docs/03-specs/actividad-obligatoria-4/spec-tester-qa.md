# Especificación Tester QA - Actividad Obligatoria N.º 4

Responsable: Lautaro Chavez
Rol: Tester QA

## 1. Objetivo

Verificar el correcto funcionamiento de la aplicación mediante
pruebas automatizadas, documentar resultados y reportar errores.

## 2. Tareas

- Crear models.spec.js.
- Crear storage.spec.js.
- Refactorizar script.spec.js.
- Ejecutar pruebas automatizadas con Jasmine.
- Utilizar Playwright MCP para verificar el funcionamiento.
- Documentar resultados y evidencias.
- Registrar errores encontrados mediante Issues en GitHub.

## 3. Herramientas

- Jasmine para pruebas automatizadas.
- Playwright MCP para pruebas de interacción.
- GitHub Issues para reportar defectos.
- Git y GitHub para gestionar cambios.

## 4. Criterios de aceptación

- [ ] models.spec.js creado.
- [ ] storage.spec.js creado.
- [ ] script.spec.js refactorizado.
- [ ] Pruebas Jasmine ejecutadas.
- [ ] Verificaciones con Playwright realizadas.
- [ ] Evidencias documentadas.
- [ ] Errores reportados mediante Issues.
- [ ] testing-doc.md actualizado.

## 5. Evidencias

Se registrarán los casos de prueba, resultados obtenidos,
capturas de pantalla y errores detectados.

No se considerarán ejecutadas las pruebas hasta contar
con resultados verificables.

Especificación inicial del rol Tester QA para la
Actividad Obligatoria N.º 4.
