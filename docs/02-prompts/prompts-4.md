# Prompt 4 - Creación del mockup

## Objetivo

Crear un mockup visual de la página web de **Heladería Vainell**, tomando como referencia la estructura HTML y el diseño CSS desarrollados anteriormente.

## Prompt utilizado

> A partir del proyecto actual de **Heladería Vainell**, utilizando como referencia la estructura del archivo `index.html` y los estilos definidos en `css/style.css`, creá un mockup visual de la página web.
>
> El mockup debe representar cómo se verá la página final, respetando la estructura y distribución de las secciones existentes.
>
> Mostrá visualmente los principales elementos de la página, incluyendo:
>
> - Encabezado y logo de la heladería.
> - Menú de navegación.
> - Sección principal o presentación.
> - Productos y sabores.
> - Promociones.
> - Información de contacto.
> - Pie de página.
>
> Utilizá una estética relacionada con una heladería, manteniendo una apariencia moderna, atractiva y coherente con la identidad visual de **Heladería Vainell**.
>
> El diseño debe ser claro, ordenado y fácil de visualizar, teniendo en cuenta la distribución de los elementos y la experiencia del usuario.
>
> El mockup debe servir como representación visual del resultado esperado de la página web.

## Resultado esperado

Obtener una representación visual de la página de **Heladería Vainell** que permita observar cómo estarán distribuidos los diferentes elementos y secciones de la interfaz.

El mockup debe permitir verificar:

- La distribución general de la página.
- La ubicación de los elementos principales.
- La organización de las diferentes secciones.
- La identidad visual de la heladería.
- La coherencia entre el diseño propuesto y la estructura HTML/CSS.

## Propósito

Este cuarto paso permite visualizar el resultado esperado del proyecto antes de realizar los ajustes finales, facilitando la detección de posibles problemas de diseño, distribución o experiencia de usuario.
