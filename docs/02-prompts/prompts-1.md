# Prompt 1 - Estructura base del proyecto

## Objetivo

Crear la estructura inicial del proyecto web **Heladería Vainell**, organizando los archivos y carpetas necesarios para comenzar el desarrollo de la página.

## Prompt utilizado

> Quiero crear la estructura base para un proyecto web de una heladería llamado **Heladería Vainell**.
>
> El proyecto debe estar organizado de forma clara y sencilla, separando los archivos HTML, CSS, JavaScript, imágenes y documentación.
>
> Creá una estructura de carpetas y archivos adecuada para un proyecto web académico, teniendo en cuenta que posteriormente se incorporará el diseño visual, la funcionalidad y un mockup.
>
> Por el momento, solamente necesito definir la estructura del proyecto. No agregues código innecesario ni funcionalidades.

## Resultado esperado

La estructura inicial del proyecto debe permitir organizar correctamente los diferentes recursos que se incorporarán durante el desarrollo, facilitando el mantenimiento y la evolución del proyecto.

Una estructura posible es:

```text
HeladeriaVainell/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/
│   └── ...
├── docs/
│   └── ...
└── README.md
