# Prompt 3 - Estilo CSS y diseño responsivo

## Objetivo

Aplicar estilos visuales al proyecto **Heladería Vainell** mediante CSS, buscando una interfaz atractiva, clara y adaptable a diferentes tamaños de pantalla.

## Prompt utilizado

> A partir del archivo `index.html` creado para **Heladería Vainell**, desarrollá el archivo `css/style.css`.
>
> Aplicá un diseño visual relacionado con una heladería, utilizando una estética agradable, moderna y coherente con la identidad de Vainell.
>
> Organizá correctamente los estilos para las diferentes secciones de la página, incluyendo el encabezado, menú de navegación, presentación, productos, promociones, contacto y pie de página.
>
> Utilizá CSS limpio, ordenado y correctamente indentado.
>
> Incorporá un diseño responsive mediante media queries para que la página pueda adaptarse correctamente a computadoras, tablets y dispositivos móviles.
>
> Priorizá una buena distribución de los elementos, legibilidad del contenido y facilidad de navegación.
>
> No agregues funcionalidades JavaScript. En esta etapa trabajá únicamente sobre el diseño y los estilos CSS.

## Resultado esperado

Obtener un archivo `style.css` que permita darle identidad visual a la página de **Heladería Vainell**, mejorando la presentación del contenido y manteniendo una correcta visualización en diferentes dispositivos.

El diseño debe contemplar:

- Estilos para el encabezado y menú de navegación.
- Diseño visual para las diferentes secciones.
- Presentación organizada de los productos.
- Estilos para promociones y contenido destacado.
- Diseño del formulario o información de contacto.
- Estilos para el pie de página.
- Adaptación responsive para dispositivos móviles, tablets y computadoras.
- Código CSS organizado y fácil de mantener.

## Propósito

Este tercer paso permite transformar la estructura HTML en una interfaz visual completa y adaptable, preparando el proyecto para la creación del mockup y las siguientes etapas de desarrollo.
